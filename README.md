# Приложение-сервер на с++, который прослушивает tty устройство и отвечает на AT команды
```text
Словарь ожиданий в виде ограниченного синтаксиса регулярных выражений 
(точка - один любой символ, * - ноль или любой символ) и ответов к ним 
разместить в csv файле или текстовом файле expect=answer. 
Базовый тестовый набор команд: AT, ATE[1,0],  ATI, AT+COPS, AT+CPIN.

Нельзя использовать библиотеку для разбора регулярных выражений в решении
```

## Установка зависимостей

```bash
sudo apt update
sudo apt upgrade
sudo apt install screen
```

## Запуск и тестирование
* Переходим в рабочую папку.
* В терминале компилируем и запускаем программу на C++. 

```bash
make all
./modem_sim
```

```text
В рабочей папке создается файл virtual-tty для виртуального терминала.
При завершении работы файл удаляется.
В процессе работы программа выводит отладочную информацию.
```

* Программа запускает второй терминал (screen ./virtual-tty), в котором мы можем отправлять команды и получать ответы.
```text
Программа разработа под ОС Ubuntu. 
Если второй терминал не запускается, перейдите в main.cpp (функция open_screen_in_new_terminal) 
и замените вызов gnome-terminal на один из предложенных ниже.
```
* Для выхода из программы нажмите Ctrl+C в главном окне
